题 2 骨架（今晚先做这个）

文件：D:\dsfit\hw\q02_float_notation.c · 3 处 TODO

#include <stdio.h>

int main(void)
{
    double value;

    printf("Enter a floating-point value: ");
    if (scanf("%lf", &value) != 1) return 1;

    /* TODO-1 定点形式：用 %f */
    printf("fixed-point notation: %s\n", "TODO-1");

    /* TODO-2 指数形式：用 %e */
    printf("exponential notation: %s\n", "TODO-2");

    /* TODO-3 p 记法：先试 %a，再试 %.2a */
    printf("p notation: %s\n", "TODO-3");

    return 0;
}
验收（输入 128.5） 
fixed-point notation: 128.500000
exponential notation: 1.285000e+02
p notation: 0x1.01p+7     ← 必须用 %.2a

默认 %a 会打满 0x1.0100000000000p+7，样例要的是短形式。

    printf("%s %s\n", w1, w2);

    /* TODO-2 右对齐：宽度和值都是字母个数 */
